# Goal Tracker (Система отслеживания целей)

Консольное приложение для постановки личных целей, их категоризации и отслеживания прогресса выполнения.

## Назначение

Помогает пользователю структурировать личные и рабочие цели, разбивать их по категориям и контролировать прогресс.

## Целевая аудитория

- Люди, стремящиеся к саморазвитию.
- Студенты, планирующие учебные проекты.
- Специалисты, систематизирующие рабочие задачи.

## Предметная область

Управление личными целями и задачами. Пользователь создаёт цели с описанием, сроком выполнения и категорией, а затем отмечает этапы выполнения.

## Основные сущности

- **Категория (Category):** группа для целей (Работа, Здоровье и т.д.).
- **Цель (Goal):** название, описание, категория, приоритет, дедлайн, прогресс, статус.

## Возможности

- Просмотр, добавление, удаление целей.
- Обновление прогресса и отметка цели выполненной.
- Поиск целей по названию.
- Фильтрация по категории и статусу.
- Сортировка по дедлайну.
- Работа с категориями.
- Статистика по целям (всего, выполнено, средний прогресс).
- Сохранение данных в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска и меню приложения;
- `goals.py` — работа с целями;
- `categories.py` — работа с категориями;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат хранения данных

Данные хранятся в JSON:

- `data/goals.json` — список целей;
- `data/categories.json` — список категорий.
