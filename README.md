# Goal Tracker (Система отслеживания целей)

## Назначение

Веб-приложение, позволяющее пользователям ставить личные цели, разбивать их на категории и отслеживать прогресс выполнения. Помогает структурировать задачи и повышать личную продуктивность.

## Целевая аудитория

- Люди, стремящиеся к саморазвитию.
- Студенты, планирующие учебные проекты.
- Cпециалисты, желающие систематизировать рабочие задачи.

## Предметная область

Управление личными целями и задачами. Пользователь создает цели с описанием, сроком выполнения и категорией, а затем отмечает этапы выполнения.

## Основные сущности

- **Пользователь (User):** владелец целей.
- **Категория (Category):** группа для целей (например, Работа, Здоровье).
- **Цель (Goal):** содержит название, описание, дату создания, дедлайн, статус выполнения и привязку к категории.

## Основные функции

- Создание, просмотр, редактирование и удаление целей.
- Фильтрация и сортировка целей по категориям и статусу.
- Отметка цели как выполненной.
- Просмотр статистики прогресса по категориям.
