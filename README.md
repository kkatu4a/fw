# Goal Tracker (Система отслеживания целей)

Консольное приложение для постановки личных целей, их категоризации, разбиения на этапы и отслеживания результатов.

## Назначение

Помогает пользователю структурировать личные и рабочие цели, разбивать их на этапы, фиксировать результаты и контролировать прогресс.

## Целевая аудитория

- Люди, стремящиеся к саморазвитию.
- Студенты, планирующие учебные проекты.
- Специалисты, систематизирующие рабочие задачи.

## Предметная область

Управление личными целями. Пользователь создаёт цели с описанием, категорией и дедлайном, разбивает их на этапы и фиксирует результаты.

## Основные сущности

### User

Владелец целей.

- Атрибуты: `id`, `name`, `email`.
- Методы: `__str__()`, `from_data()`, `to_data()`.

### Category

Группа для целей (Работа, Здоровье, Личное развитие).

- Атрибуты: `id`, `name`.
- Методы: `__str__()`, `from_data()`, `to_data()`.

### Goal

Цель пользователя.

- Атрибуты: `id`, `title`, `description`, `category`, `priority`, `created_date`, `deadline`, `progress`, `is_completed`.
- Методы: `get_priority_label()`, `get_progress_status()`, `update_progress()`, `complete()`, `days_left()`, `__str__()`, `from_data()`, `to_data()`.

### Stage

Промежуточный шаг на пути к цели.

- Атрибуты: `id`, `title`, `goal`, `is_done`.
- Методы: `complete()`, `__str__()`, `from_data()`, `to_data()`.

### Result

Итог выполнения цели.

- Атрибуты: `id`, `description`, `goal`, `achieved`.
- Методы: `mark_achieved()`, `__str__()`, `from_data()`, `to_data()`.

## Взаимодействие объектов

- `Stage` связан с `Goal` через атрибут `goal`.
- `Result` связан с `Goal` через атрибут `goal`.
- `Goal` связан с `Category` через атрибут `category`.
- В `data/*.json` связи хранятся через идентификаторы (`category_id`, `goal_id`).
- При загрузке `storage.py` восстанавливает ссылки на объекты.

## Возможности

- Просмотр, добавление пользователей.
- Просмотр, добавление категорий.
- Просмотр, добавление, удаление целей.
- Обновление прогресса и отметка цели выполненной.
- Поиск целей по названию.
- Фильтрация по категории и статусу.
- Сортировка по дедлайну.
- Работа с этапами цели: добавление, отметка выполненными, автоматический расчёт прогресса цели по этапам.
- Работа с результатами: добавление, отметка достигнутыми.
- Статистика по целям.
- Сохранение данных в JSON-файлах.

## Формат хранения данных

Данные хранятся в JSON-файлах в каталоге `data/`. Связанные объекты хранятся через идентификаторы:

- `goals.json` — `category_id`;
- `stages.json` — `goal_id`;
- `results.json` — `goal_id`.

При загрузке `storage.py` преобразует словари в объекты и восстанавливает связи.
